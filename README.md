# Product Engineering Lab

가상의 사용자 요구사항을 바탕으로 여러 서비스를 직접 기획하고, 설계·구현·테스트·검증까지 전체 제품 개발 과정을 진행하며 기록하는 모노레포입니다.

각 서비스는 하나의 완결된 제품처럼 다음 단계를 거칩니다.

1. **기획** — 문제 정의, 사용자 시나리오, 기능 요구사항, 업무 규칙
2. **설계** — 화면·사용자 흐름, 데이터 모델(ERD), API 명세, 아키텍처
3. **구현** — 백엔드·프론트엔드 코드
4. **테스트·검증** — 테스트 계획, 완료 기준 검증

## 디렉터리 구조

프로젝트는 브랜치가 아니라 디렉터리로 분리해 관리합니다. 각 프로젝트는 자신만의 `README.md`를 가진 독립적인 단위입니다.

```
product-engineering-lab/
└── projects/
    └── <project-name>/
        ├── README.md       프로젝트 소개, 기능, 구조, 실행 방법
        ├── docs/           기획·설계 문서
        ├── frontend/        클라이언트 애플리케이션 (있는 경우)
        └── backend/         서버 애플리케이션 (있는 경우)
```

새 프로젝트를 추가할 때는 `projects/` 아래에 같은 형태의 디렉터리를 만들고, 위 표에 한 줄을 추가합니다.
