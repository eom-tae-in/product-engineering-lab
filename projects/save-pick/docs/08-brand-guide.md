# savePick 브랜드 가이드

- 문서 ID: 08
- 작성: experience-designer
- 최종 갱신: 2026-08-28
- 선행 문서: 01, 02, 06, 07

## 한 줄 요약
savePick이 전달할 세 가지 인상(신선함·신뢰감·합리적인 소비)을 색·타이포·여백·문구 규칙으로 옮기고, 화면과 와이어프레임이 그대로 참조할 컬러·타이포 토큰과 로고 사용 규칙을 확정한다.

---

## 1. 브랜드 한 줄 정의

> **savePick은 마감 임박 신선식품을 "떨이"가 아니라 "합리적 선택"으로 사게 하는 매장 픽업 서비스다.**

표기는 항상 `savePick`이다. `s`는 소문자, `P`는 대문자다. `SavePick`, `SAVEPICK`, `Save Pick`으로 쓰지 않는다.

## 2. 전달할 인상과 디자인 근거

### 2.1 신선함

| 결정 | 내용 | 근거 |
|---|---|---|
| 주 색상을 딥 그린으로 | `--color-brand: #17795E` | 신선식품이 다루는 대상은 채소·육류·과일이다. 그린은 이 카테고리와 가장 직접적으로 연결되는 색이며, 밝은 라임이 아니라 어두운 딥 그린을 써야 저가 이미지 대신 품질 이미지를 준다 |
| 잔여 시간·신선도 표시를 별도 색으로 분리 | `--color-fresh: #2FA37A` | 마감까지 남은 시간은 "위험"이 아니라 "상태 정보"다. 위험색을 쓰면 상품이 상한 것처럼 읽힌다 |
| 넉넉한 여백 | 카드 안쪽 여백 16px, 카드 사이 12px, 섹션 사이 24px | 상품이 빽빽하게 쌓인 매대는 "정리 안 된 떨이 코너"를 연상시킨다. 여백은 상품 한 점 한 점을 골라 놓은 것처럼 보이게 한다 |
| 페이지 배경을 순백이 아닌 옅은 그린 그레이로 | `--color-bg: #F4F7F5` | 순백 위 흰 카드는 경계가 흐려진다. 아주 옅은 그린 톤은 카드를 띄우면서 서비스 전체에 신선한 인상을 얇게 깔아 준다 |

### 2.2 신뢰감

| 결정 | 내용 | 근거 |
|---|---|---|
| 하나의 서체, 5개 타이포 토큰만 사용 | Pretendard 기반 5단계 | 서체가 섞이면 정보의 신뢰도가 떨어진다. 크기·굵기 5단계면 목록·상세·주문서를 모두 표현할 수 있다 |
| 가격에 고정폭 숫자 사용 | `font-variant-numeric: tabular-nums` | 목록에서 가격 자릿수가 흔들리면 비교가 어렵고 값이 부정확해 보인다 |
| 8px 배수 그리드 | 여백 4 / 8 / 12 / 16 / 24 / 32 | 정돈된 간격은 "관리되고 있는 매장"이라는 인상을 만든다 |
| 상태 배지 색을 상태 의미에만 사용 | 확정·준비 완료는 브랜드색, 취소·완료는 무채색, 노쇼·결제 실패만 위험색 | 색이 상태와 1:1로 대응해야 고객이 색만 보고 자기 주문 상태를 판단할 수 있다 |
| 시각을 항상 명시 | `19:00까지 취소 가능`, `21:00에 노쇼 처리` | 서버 시각 기준 판정(BR-028)을 화면에 숨기지 않는다. 언제 무슨 일이 일어날지 미리 말해 주는 것이 신뢰의 최소 조건이다 |

### 2.3 합리적인 소비

| 결정 | 내용 | 근거 |
|---|---|---|
| 할인가에 붉은색을 쓰지 않는다 | `--color-discount: #0B5FA5` (딥 블루) | 붉은 세일 표기는 "재고 처분"을 연상시킨다. 파랑은 정보·숫자·계산의 색이며, 할인가를 감정이 아니라 근거로 읽게 만든다 |
| 정가·할인율·절약 금액을 항상 함께 노출 | `12,000원` 취소선 / `8,400원` / `30% 할인 · 3,600원 아낌` | 합리적 선택은 비교가 가능해야 성립한다. 할인가만 크게 두면 근거 없는 가격이 된다 |
| 잔여 수량 강조를 3개 이하로 제한 | 4개 이상은 보조색, 3개 이하만 `--color-warning` | 항상 강조하면 압박이 되고, 압박은 "지금 안 사면 손해"라는 떨이 문법이다 |
| 카운트다운은 선점 타이머에만 쓴다 | 상품 목록·상세에 초 단위 카운트다운을 두지 않는다 | 선점 타이머는 고객의 재고를 실제로 잡아 둔 시간이라 알릴 의무가 있다. 상품 목록의 카운트다운은 근거 없는 조급함만 만든다 |
| 마감 시각을 시각으로 표기 | `오늘 21:00 마감` (`3시간 남음`이 아니라) | 절대 시각은 고객이 자기 일정과 비교해 판단하게 한다. 상대 시간은 초조함을 만든다 |

### 3.3 색 사용 금지 규칙

| # | 규칙 | 이유 |
|---|---|---|
| 1 | 할인율·할인가·절약액에 `--color-danger`를 쓰지 않는다 | 할인은 좋은 소식이다. 위험색은 품절·결제 실패·노쇼에만 쓴다 |
| 2 | `--color-fresh`를 14~15px 본문 텍스트 색으로 쓰지 않는다 | 대비 3.2:1로 본문 기준에 미달한다 |
| 3 | 잔여 수량이 4개 이상일 때 `--color-warning`을 쓰지 않는다 | 상시 경고는 압박 문법이다 |
| 4 | 한 화면에 브랜드색 채운 버튼을 2개 이상 두지 않는다 | 주요 액션이 하나여야 결정을 돕는다 |
| 5 | 토큰 밖의 색상값을 화면에 직접 쓰지 않는다 | 와이어프레임·구현 전반에서 색이 갈라지는 것을 막는다 |

## 4. 타이포 토큰

### 4.1 서체

```
Pretendard, -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo",
"Noto Sans KR", "Malgun Gothic", sans-serif
```

Pretendard를 1순위로 둔다. 한글 자소 균형이 좋고 숫자 폭이 일정해 가격 비교 화면에 적합하다. 폴백은 iOS·Android·Windows 기본 한글 서체 순으로 지정한다.

### 4.2 토큰

| 토큰 | 용도 | 크기 / 굵기 / 행간 |
|---|---|---|
| `--font-display` | 로고타입, 화면 제목, 픽업 번호 | 22px / 700 / 1.3 |
| `--font-heading` | 섹션 제목, 카드 상품명 | 17px / 600 / 1.4 |
| `--font-body` | 본문, 버튼 라벨 | 15px / 400 / 1.6 |
| `--font-price` | 할인가, 결제 금액 | 20px / 700 / 1.3, `tabular-nums`, `letter-spacing: -0.01em` |
| `--font-caption` | 보조 정보, 정가 취소선, 상태 캡션 | 13px / 400 / 1.5 |

**규칙**
- 모바일 본문은 15px 아래로 내리지 않는다. `--font-caption` 13px은 부가 정보에만 쓰고, 이 값에만 담긴 내용이 없어야 한다.
- 가격은 어떤 화면에서도 16px 아래로 내리지 않는다. 목록 카드에서도 `--font-price`를 쓴다.
- 픽업 번호(SC-008)는 예외적으로 `--font-display`를 40px로 키운다. 매장에서 구두로 읽는 값이라 한눈에 보여야 한다.
- 대문자 변환(`text-transform: uppercase`)을 쓰지 않는다. 한글에 효과가 없고 영문 로고 표기 규칙과 충돌한다.

### 4.3 여백 스케일

| 토큰 | 값 | 용도 |
|---|---|---|
| `--space-1` | 4px | 배지 안쪽 여백 |
| `--space-2` | 8px | 인접 텍스트 사이 |
| `--space-3` | 12px | 카드 사이 |
| `--space-4` | 16px | 카드 안쪽, 화면 좌우 여백 |
| `--space-6` | 24px | 섹션 사이 |
| `--space-8` | 32px | 화면 상단 여백, 빈 상태 블록 |

360px 기준 화면 좌우 여백은 16px로 고정한다. 콘텐츠 폭은 328px이다.

### 4.4 모서리와 그림자

| 토큰 | 값 | 용도 |
|---|---|---|
| `--radius-sm` | 6px | 배지, 칩 |
| `--radius-md` | 10px | 버튼, 입력 필드 |
| `--radius-lg` | 14px | 카드, 시트 |
| `--shadow-card` | `0 1px 2px rgba(26,31,28,.06)` | 카드 |
| `--shadow-sheet` | `0 -4px 16px rgba(26,31,28,.12)` | 하단 고정 바, 시트 |

그림자는 두 단계만 쓴다. 단계가 늘면 화면이 산만해지고 신뢰감이 떨어진다.

## 5. 로고

### 5.1 파일

| 파일 | 용도 |
|---|---|
| `assets/logo/logo-full.svg` | 심볼 + 로고타입 가로형. 헤더, 문서 표지 |
| `assets/logo/logo-symbol.svg` | 심볼 단독. 앱 아이콘, 파비콘 |
| `assets/logo/logo-mono.svg` | 단색. 인쇄, 영수증, 배경 위 |

### 5.2 심볼 개념

심볼은 **체크 표시의 긴 획을 잎사귀로 바꾼 형태**다.

| 요소 | 의미 |
|---|---|
| 체크 | 고르다 · 선택하다 (`Pick`) — 합리적 선택 |
| 잎사귀 | 신선식품 — 신선함 |
| 라운드 스퀘어 배경 | 매장이라는 하나의 물리적 장소 — 신뢰감 |

체크와 잎사귀를 한 획으로 잇는 이유는 "고르는 행위"와 "신선함"이 이 서비스에서 분리되지 않기 때문이다. 24×24로 축소해도 잎의 비대칭 실루엣과 체크의 짧은 획이 남아 형태가 식별된다.

### 5.3 색

| 요소 | 색 |
|---|---|
| 배경 라운드 스퀘어 | `--color-brand` `#17795E` |
| 잎사귀 | `#7BD0A8` (브랜드 그린의 밝은 파생값) |
| 체크 짧은 획 | `#FFFFFF` |
| 로고타입 | `--color-brand` `#17795E` |

색상은 2색(딥 그린 + 라이트 그린) + 무채색(흰색)으로 제한한다.

### 5.4 사용 규칙

| 항목 | 규칙 |
|---|---|
| 최소 크기 | `logo-full` 가로 96px, `logo-symbol` 24px |
| 보호 여백 | 심볼 높이의 25% 이상을 로고 사방에 비운다 |
| 배경 | 흰색, `--color-bg`, `--color-brand` 위에만 올린다. 사진 위에 올릴 때는 `logo-mono`를 쓴다 |
| 크기 지정 | SVG에 `viewBox`만 두고 고정 `width`/`height`를 넣지 않는다 |

**금지 사용례**

| # | 금지 | 이유 |
|---|---|---|
| 1 | 로고타입의 자간·비율 변경 | 로고타입은 형태 자체가 식별자다 |
| 2 | 브랜드 색 외의 색으로 재도색 | 색이 브랜드 인지의 절반이다 |
| 3 | 심볼 안에 할인율·`SALE` 등 문자 삽입 | 로고가 프로모션 배지로 읽힌다 |
| 4 | 심볼에 그림자·그라디언트 적용 | 24px에서 형태가 뭉개진다 |
| 5 | `SavePick`, `SAVEPICK`, `Save Pick` 표기 | 표기 규칙 위반 |

## 6. 가격·할인 표기 규칙

### 6.1 표준 표기

```
삼겹살 500g
12,000원          ← 정가, 취소선, --color-text-weak, --font-caption
8,400원           ← 할인가, --color-discount, --font-price
30% 할인 · 3,600원 아낌   ← --color-brand 텍스트 / --color-brand-weak 배경 배지
```

| # | 규칙 |
|---|---|
| 1 | 할인가가 화면에서 가장 큰 가격 요소다. 정가가 할인가보다 크게 표시되지 않는다 |
| 2 | 할인율과 절약 금액을 항상 함께 보여 준다. 둘 중 하나만 쓰지 않는다 |
| 3 | 할인율 0%(마감까지 24시간 초과) 상품에는 할인 배지와 정가 취소선을 표시하지 않고 가격 하나만 보여 준다 |
| 4 | 할인가는 10원 단위 내림 결과를 그대로 쓰고 최저 100원으로 표시한다 (BR-004) |
| 5 | 금액에는 항상 세 자리 구분 쉼표와 `원`을 붙인다. `8.4천원` 같은 축약을 쓰지 않는다 |
| 6 | 할인 배지에 `!`, `최저가`, `역대급` 같은 표현을 쓰지 않는다 |

### 6.2 잔여 수량 표기

| 잔여 수량 | 표기 | 색 |
|---|---|---|
| 6개 이상 | `남은 수량 8개` | `--color-text-weak` |
| 4~5개 | `남은 수량 5개 · 소진 임박` | `--color-text-weak` (문구로만 알림) |
| 1~3개 | `남은 수량 2개 · 소진 임박` | `--color-warning` |
| 0개 | `품절` | `--color-danger` |

`05-state-rules.md`와 `03-functional-requirements.md`는 5개 이하를 소진 임박으로 정의한다(FR-015). 소진 임박 **문구**는 5개 이하부터 붙이고, **경고색 강조**는 3개 이하부터 적용한다. 문구와 색 강조를 분리해 압박 강도를 조절한다.

### 6.3 시간 표기

| 대상 | 표기 | 이유 |
|---|---|---|
| 상품 마감 시각 | `오늘 21:00 마감` | 절대 시각으로 고객 일정과 비교하게 한다 |
| 픽업 시간대 | `오늘 20:00~20:30` | 시작·종료를 모두 보여 준다 |
| 취소 가능 마감 | `19:00까지 취소 가능` | 기준 시각을 숨기지 않는다 |
| 노쇼 전환 예정 | `21:00까지 오지 않으면 노쇼로 처리돼요` | 결과와 시각을 함께 말한다 |
| 선점 잔여 시간 | `09:58` (mm:ss) | 초 단위 표시는 선점 타이머 한 곳에만 쓴다 |

## 7. 톤 앤 매너

### 7.1 원칙

| # | 원칙 |
|---|---|
| 1 | 사실을 먼저 말하고 그다음에 다음 행동을 제안한다 |
| 2 | 고객을 탓하지 않는다. 실패의 주어를 고객으로 두지 않는다 |
| 3 | 느낌표를 쓰지 않는다. 강조는 색과 크기로 한다 |
| 4 | 존댓말 `-요` 체를 쓴다. `-습니다`는 쓰지 않는다 |
| 5 | 시스템 상태값(PENDING, CONFIRMED)을 고객 화면에 그대로 노출하지 않는다 |

### 7.2 문구 예시

| 상황 | 좋은 예 | 나쁜 예 |
|---|---|---|
| 마감 할인 안내 | `마감까지 3시간, 50% 할인이 적용됐어요` | `떨이 대방출! 반값 특가!!` |
| 잔여 수량 | `남은 수량 2개 · 소진 임박` | `단 2개! 지금 안 사면 놓칩니다` |
| 품절 | `품절됐어요. 다른 상품을 둘러보세요` | `이미 다 팔렸습니다` |
| 선점 만료 | `선점 시간이 끝났어요. 담아 둔 상품으로 다시 주문할 수 있어요` | `시간이 초과되어 주문이 취소되었습니다` |
| 만료 임박 | `1분 뒤 선점이 풀려요. 시간은 연장되지 않아요` | `서두르세요! 곧 사라집니다!!` |
| 결제 실패 | `결제가 완료되지 않았어요. 2번 더 시도할 수 있어요` | `결제 실패. 카드 정보를 다시 확인하세요` |
| 재고 부족 | `방금 다른 고객이 먼저 담았어요. 남은 수량은 1개예요` | `주문 실패: 재고 부족` |
| 시간대 마감 | `이 시간대는 예약이 마감됐어요 (시작 30분 전까지 예약 가능)` | `선택 불가` |
| 취소 불가 | `19:00에 취소 가능 시각이 지났어요. 매장으로 문의해주세요` | `취소할 수 없습니다` |
| 노쇼 | `21:00에 노쇼로 처리됐어요. 결제 금액은 환불되지 않아요` | `노쇼 처리되었습니다. 주의하세요` |
| 주문 제한 | `노쇼 3회로 2026-09-04 19:00까지 새 주문을 만들 수 없어요` | `이용이 정지되었습니다` |
| 빈 상태 | `지금 판매 중인 상품이 없어요. 영업시간은 10:00~22:00입니다` | `데이터가 없습니다` |
| 오류 | `상품을 불러오지 못했어요` + `다시 시도` | `Error: 알 수 없는 오류가 발생했습니다` |

### 7.3 쓰지 않는 어휘

`떨이`, `땡처리`, `재고 정리`, `폭탄 세일`, `역대급`, `초특가`, `마지막 기회`, `놓치지 마세요`, `서두르세요`

이 어휘들은 모두 상품의 가치가 아니라 고객의 조급함을 근거로 삼는다. savePick의 판매 근거는 "마감이 가까워 값이 내려갔다"는 사실 하나이며, 그 사실만으로 충분하다.

### 7.4 버튼 라벨 규칙

| 규칙 | 예 |
|---|---|
| 동사로 끝낸다 | `장바구니 담기`, `픽업 시간 고르기`, `결제하기` |
| 결과를 예측할 수 있게 쓴다 | `전체 취소하기` (`확인` 아님) |
| 파괴적 액션은 결과를 명시한다 | `주문서 포기` (`나가기` 아님) |
| 금액이 걸린 버튼은 금액을 포함한다 | `12,300원 결제하기` |
