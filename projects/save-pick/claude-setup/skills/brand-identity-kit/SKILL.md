# savePick 브랜드 아이덴티티

## 전달할 인상

**신선함 · 신뢰감 · 합리적인 소비.**

이 서비스는 "떨이"가 아니라 "좋은 걸 좋은 값에". 마감 임박을 부끄러운 정보가 아니라 **똑똑한 선택의 근거**로 보이게 한다.
할인 표기가 상품을 싸구려로 보이게 하면 브랜드가 실패한다.

- 신선함 → 그린 계열, 넉넉한 여백, 선명한 상품 사진
- 신뢰감 → 정돈된 그리드, 일관된 타이포, 과장 없는 문구
- 합리적 소비 → 원가·할인가·절약액을 숨기지 않고 명확히 비교

피할 것: 빨간 폭탄 세일 배지, 카운트다운 압박, 느낌표 남발, "떨이/땡처리" 어휘.

## 컬러 토큰

용도 기반으로 정의한다. 색상값은 설계 시 확정하되 **토큰 이름은 아래를 그대로 쓴다.**

```markdown
| 토큰 | 용도 | 값 |
|---|---|---|
| --color-brand | 주 브랜드색 (CTA, 강조) | |
| --color-brand-weak | 브랜드색 배경 | |
| --color-fresh | 신선도·잔여시간 표시 | |
| --color-discount | 할인가·절약액 | |
| --color-warning | 잔여 수량 부족, 선점 만료 임박 | |
| --color-danger | 품절, 결제 실패 | |
| --color-text | 본문 | |
| --color-text-weak | 보조 정보, 원가 취소선 | |
| --color-surface | 카드 배경 | |
| --color-bg | 페이지 배경 | |
| --color-border | 구분선 | |
```

규칙:
- `--color-discount`는 위험(danger)과 **다른 색**이어야 한다. 할인은 좋은 소식이다.
- 품절·실패에만 danger를 쓴다. 할인율에 쓰지 않는다.
- 본문 텍스트와 배경의 명도 대비 4.5:1 이상, 큰 텍스트 3:1 이상을 지킨다.
- 라이트 모드를 기준으로 정의하고, 다크 모드는 토큰 재정의로 처리한다.

## 타이포

```markdown
| 토큰 | 용도 | 크기/굵기 |
|---|---|---|
| --font-display | 로고, 화면 제목 | |
| --font-heading | 섹션 제목 | |
| --font-body | 본문 | |
| --font-price | 가격 | |
| --font-caption | 보조 정보 | |
```

- 한글 가독성이 좋은 서체를 쓰고 폴백을 함께 적는다.
- 가격은 숫자 정렬이 흔들리지 않는 서체·설정을 쓴다.
- 모바일 본문 최소 14px, 가격 최소 16px.

## 가격 표기 규칙

```
원가 12,000원 (취소선, --color-text-weak)
할인가 7,900원 (--color-discount, --font-price)
34% 할인 · 4,100원 절약
```

- 할인가가 시각적으로 가장 크다.
- 할인율과 절약 금액을 함께 보여 "합리적 선택"의 근거를 만든다.
- 잔여 수량은 3개 이하일 때만 `--color-warning`으로 강조한다. 항상 강조하면 압박이 된다.

## 로고

`assets/logo/`에 SVG로 저장한다.

| 파일 | 용도 |
|---|---|
| `logo-full.svg` | 로고타입 + 심볼 (가로형) |
| `logo-symbol.svg` | 심볼 단독 (앱 아이콘, 파비콘) |
| `logo-mono.svg` | 단색 (인쇄, 배경 위) |

규칙:
- 순수 SVG. 텍스트는 패스가 아니라 `<text>`로 두되 폰트 폴백을 지정하거나, 패스화했다면 원본 폰트명을 주석으로 남긴다.
- `viewBox` 필수, 고정 `width`/`height` 금지.
- 심볼은 24×24에서도 형태가 식별되어야 한다.
- 색상은 최대 2색 + 무채색.
- 표기는 `savePick` — `s` 소문자, `P` 대문자. `SavePick`, `SAVEPICK`으로 쓰지 않는다.

## 브랜드 가이드 문서 구성

`docs/08-brand-guide.md`에 다음 순서로 쓴다.

1. 브랜드 한 줄 정의
2. 전달할 인상 3가지와 **각각을 어떤 디자인 결정으로 표현했는지 근거**
3. 컬러 토큰표 (값 포함)
4. 타이포 토큰표
5. 로고 사용 규칙 (최소 크기, 여백, 금지 사용례)
6. 가격·할인 표기 규칙
7. 톤 앤 매너 (문구 예시: 좋은 예 / 나쁜 예)
8. 가정 / 미확정

근거 없는 색 선택은 적지 않는다. "왜 이 색인가"가 없으면 가이드가 아니라 취향이다.
