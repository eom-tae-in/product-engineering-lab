savePick 설계의 현재 상태를 점검해 보고한다. **문서를 수정하지 않는다.**

1. `docs/00-status.md`를 읽어 게이트 상태를 확인한다.
2. `docs/` 하위 파일 목록을 확인해 각 번호대 문서의 존재 여부를 표로 보여준다.
3. `docs/15-review-report.md`가 있으면 `수정필요` 문서 목록을 뽑는다.
4. 모든 문서의 「가정 / 미확정」 섹션을 모아 **사용자 결정이 필요한 항목**을 한 목록으로 정리한다.
5. 다음에 실행해야 할 게이트를 한 줄로 알려준다.

출력 형식:

```
## 게이트 상태
## 문서 현황 (있음/없음)
## 수정필요 문서
## 사용자 결정 대기 항목
## 다음 작업
```
